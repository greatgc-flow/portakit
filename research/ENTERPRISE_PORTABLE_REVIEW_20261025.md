### Critically corrected or unverified claims

1. **pymcprotocol is not a drop-in virtual Mitsubishi PLC server.** Its upstream README explains computer-to-PLC client operation (`Type3E().connect()`), 3E tested and 4E implemented but not tested. The report includes a separate hand-written TCP server snippet with `0.0.0.0:5000`, minimal length/framing checks, unbounded/client-controlled point handling and broad exception swallowing. **Do not copy, compile, run or distribute that snippet.** Real virtual 3E server work belongs in a separate reviewed simulator codebase with localhost default, explicit test-only remote binding, per-client authentication/limits where appropriate, bounded memory/requests, strict frame tests and fuzzing. [Upstream](https://github.com/senrust/pymcprotocol).
2. **Everything first-run.** The report proposes `install_service=1` while also promising no admin/service changes. This violates PortaKit's fail-closed operational policy. Upstream says service installation requires elevation and NTFS whole-volume indexing can expose sensitive path metadata. Leave **all indexing/service/HTTP/ETP settings untouched by default** and permit only approved folder-only human tests. [Vendor docs](https://www.voidtools.com/support/everything/everything_service/).
3. **PowerShell 7 on Server 2008 R2 is unsupported as a blanket claim.** ZIP deployment does not make Windows ABI/.NET/runtime constraints disappear. Do not use new `pwsh.exe` as a compatibility bypass on unverified legacy servers; preserve PS2.x/5.x scripts and Windows built-ins. [Microsoft migration support](https://learn.microsoft.com/en-us/powershell/scripting/whats-new/migrating-from-windows-powershell-51-to-powershell-7).
4. **Secs4Net modern target runtimes.** At the observed upstream revision `src/Secs4Net/Secs4Net.csproj` targets `net8.0;net10.0`; not a Visual Studio 2015 / .NET Framework drop-in. Consider a separately built optional offline runtime, not a modification to PortaKit's stdlib Python core. [Upstream source](https://github.com/mkjeff/secs4net/blob/base/src/Secs4Net/Secs4Net.csproj).
5. **Sysinternals free company use does not authorize redistribution.** Microsoft publicly declines third-party redistribution licenses. Research metadata may link to official downloads but should not bundle the suite, including powerful process/service utilities. [Microsoft FAQ](https://learn.microsoft.com/en-us/sysinternals/license-faq).
6. **NSSM registers Windows services; com0com/hub4com can install drivers; GlazeWM MSI extraction is not proven admin-free** by a command example. These are explicitly out of zero-mutation default scope; preserve `RESEARCH_ONLY` until a separate supported elevated, permissioned deployment design is approved. [GlazeWM reported no-admin issue](https://github.com/glzr-io/glazewm/issues/669).
7. **Network probe tools and industrial protocols must be opt-in:** PortQry, tcping, Ncat, Packet Sender, WinMTR, BAC0, Telegraf, MQTT brokers, HSMS/OPC UA/CIP listeners all have live network behaviors. For anything beyond loopback synthetic fixtures require documented owner approval, destination and load budget. Passive offline PCAP reading is a distinct safer scenario from live capture/Npcap installation.
8. **PortQry result codes are not definitive firewall-location proof.** `FILTERED` is evidence compatible with filtering/nonresponse, not certainty of which firewall/router applied it. Verify end-to-end with controlled observations.
9. **License claims and benchmark absolutes must remain provisional:** e.g. 'commercially free' for every tool, identical launch memory claims, multi-GB logs indexed in seconds, 100% elimination of integration errors, and 'no errors' in duplicate deletion. Verify versions, direct vendor license, corporate use, redistribution notices, exact archive/hash, dependency graph and Windows workstation behavior. Do not interpret a permissive code license as a binary-redistribution permission for every combined package or extension.
